# Create tickets

Work starts as a numbered preview. Issues are created only after you say **create**, or **use #N** to bind an existing ticket.

- Chat or the ticket-required prompt → preview → reply **create** or **use #N**
- Notes or a readable URL → numbered preview → issues
- Claim an existing high-priority item from the board
- Or file from the ticket UI after sign-in ([Hosted apps](../hosted.md))

Assignees are developers from `people.json`. Ticket `@` mentions go to stakeholders only.

Hooks never create issues in the same turn as the numbered preview.
