# Autodevelop handbook

Copyright (c) 2026 Devrecated.

Public documentation for Autodevelop: how to install the Cursor plugin, sign in with the CLI, connect the GitHub App, bind a product repository, and use tickets, mail, and ship gates.

This repository is the VitePress site. Preview locally:

```bash
pnpm install
pnpm docs:dev
```

The site opens at `http://localhost:5173/autodevelop-docs/`.

The published handbook is [https://devprecated.github.io/autodevelop-docs/](https://devprecated.github.io/autodevelop-docs/). Pushes to `master` deploy it with GitHub Actions.
